# Bedly Legal

Public support and privacy pages for **Bedly: Wake Up Alarm**.

## Purpose

This repository hosts the lightweight public pages required for app distribution and user support:

- Support page
- Privacy policy
- Landing index linking to both resources

## Tech Stack

- Static HTML
- CSS embedded per page
- GitHub Pages

## Files

```text
.
|-- index.html      # Entry page
|-- support.html    # Support information for users
`-- privacy.html    # Privacy policy
```

## Deployment

The site is designed to be served as static files through GitHub Pages.

## Status

This is a public legal/support companion repo for the Bedly iOS app. It is intentionally small and dependency-free.
